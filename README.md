📌 About The Project

This is my personal developer portfolio website, designed to present my technical skills, projects and contact information in a clean and professional way.

The application uses a React-based frontend and a Python/Django backend to dynamically manage and display portfolio content through APIs.

✨ Key Features
📱 Fully responsive design for mobile, tablet and desktop.
🏠 Modern and interactive homepage.
👨‍💻 About section to introduce myself.
🛠️ Dynamic skills section.
🚀 Projects showcase with descriptions and technologies.
🔗 Backend API integration.

⚙️ Run Locally
1. Clone the repository
bash
git clone https://github.com/Manthan612/manthan-portfolio.git

2. Frontend Setup
bash
cd manthan-portfolio/frontend
npm install
npm run dev

3. Backend Setup

Open another terminal:

bash
cd manthan-portfolio/backend
python -m venv venv


Activate the virtual environment.

Windows:

bash
venv\Scripts\activate


Install dependencies:

bash
pip install -r requirements.txt


Run database migrations:

bash
python manage.py migrate


Start Django server:

bash
python manage.py runserver
